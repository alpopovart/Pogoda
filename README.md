# Погодный виджет: д. Ураково (Мариинско-Посадский округ, Чувашия)

Готовый одностраничный веб-виджет (`index.html`) с крупным мобильным режимом для телефона («Режим для мамы»), голосовым озвучиванием, отправкой сводки в WhatsApp/Telegram и ежедневным автоматическим обновлением прогноза на 7 дней по координатам д. Ураково (`56.096985, 47.878893`).

## Быстрый запуск на GitHub Pages
1. Создайте новый публичный репозиторий на GitHub (например, `urakovo-weather`).
2. Загрузите файл `index.html` из этого архива в корень репозитория и нажмите **Commit changes**.
3. Перейдите в **Settings → Pages**, в разделе **Branch** выберите ветку `main` (папка `/ (root)`) и нажмите **Save**.
4. Через 1–2 минуты ваш виджет будет доступен по адресу `https://<ваш-логин>.github.io/urakovo-weather/`.
